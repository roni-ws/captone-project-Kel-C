# captone-project-Kel-C

Aplikasi Penerimaan Siswa Baru (SPMB) berbasis web.

## Teknologi
- CodeIgniter 4
- CodeIgniter Shield
- MySQL
- Tailwind CSS
- PhpSpreadsheet, TCPDF, Grid.js

## Pengembangan
- Server dev: `php spark serve`
- Migrasi database: `php spark migrate`
- Seed data: `php spark db:seed SpmbSeeder`
- Build CSS: `npm run build`
- Test: `composer test`
